# CS-30 / CS-10 立ち座りテスト計測アプリ

スマートフォンやPCのカメラで、椅子立ち上がりテストを自動計測します。2種目に対応しています。

| 種目 | 内容 | 結果 |
|---|---|---|
| **CS-30** | 30秒間に何回立ち上がれるか | 回数 |
| **CS-10** | 10回立ち上がるまでの所要時間 | 秒数 |

骨格推定（MediaPipe Pose）で立位・座位を判定し、回数のカウント、起立・着座それぞれの所要時間と速度、波形グラフ、CSV出力までを行います。**計測が終わると、年代・性別に応じた基準値と比べた評価を、画面と音声の両方でフィードバックします。**

Windows・Android・iPhone のいずれでも、**インストールして独立したアプリとして**使えます。

## 事前準備：https で公開する

ブラウザは https のページでしかカメラを使えません。ファイルを直接ダブルクリックして開いても映像は出ないため、必ず一度どこかに公開します。無料でできる方法を2つ挙げます。

### 方法A：Tiiny Host（最も手軽・数分）

1. `cs30-app` フォルダ全体を **zip 圧縮** します
   - Windows: フォルダを右クリック →「圧縮」または「送る」→「圧縮フォルダー」
2. https://tiiny.host にアクセスします
3. 作成した zip をアップロードします
4. 好きなリンク名を入力して公開します
5. `https://（決めた名前）.tiiny.site` というURLが発行されます

> zip の中身が `cs30-app/index.html` のような入れ子になっていると動きません。
> **index.html が zip の直下に来るように**、フォルダの中身を選択して圧縮してください。

### 方法B：GitHub Pages（無料・URLが変わらない）

1. GitHub でアカウントを作り、新しいリポジトリを作成します（Public）
2. `cs30-app` の中身をすべてアップロードします
3. リポジトリの Settings → Pages を開きます
4. Source で `main` ブランチ、フォルダは `/ (root)` を選んで Save します
5. 数分後 `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます

継続して使うならこちらをおすすめします。URLが固定され、更新も差し替えるだけで済みます。

## 画面の構成

画面は2つのタブに分かれています。

| タブ | 内容 |
|---|---|
| **基本情報** | 動作モード、種目、撮影方向、対象者（年代・性別）、対象者ID、動画の保存・音声・しきい値の設定 |

## 3つの動作モード

基本情報タブのいちばん上で選びます。

### 1. リアルタイム計測

カメラで撮りながら、その場で回数と時間を自動計測します。骨格線と重心が映像に重なり、結果は計測終了と同時に表示されます。通常はこれを使います。

### 2. 撮影のみ

骨格の判定はせず、**合図と時間だけ**を入れて動画を残します。

- 骨格線は映像に出ません（きれいな映像がそのまま残ります）
- 「今から始めます。はいどうぞ」のアナウンスと、カウントダウンの音は入ります
- CS-30 は30秒で自動終了、CS-10 は「撮影を終了」を押すまで撮り続けます
- 動画は `CS30_日時_ID_side_rec.mp4` のような名前で保存されます

その場で結果を出す必要がないとき、骨格推定の負荷で映像が乱れるのを避けたいとき、あとからじっくり解析したいときに使います。撮った動画は次の「動画を解析」でそのまま読み込めます。

### 3. 動画を解析

すでに撮ってある動画を読み込んで、回数と時間を計測します。

1. 「動画ファイル」で動画を選びます
2. 「**読み取る間隔**」を選びます。30コマ/秒が最も細かく、10コマ/秒が最も速く終わります
3. 「**0秒とする位置**」を選びます
   - **最初の動き出し**（既定）：座位からはじめて座位を離れた時点を0秒とします
   - **動画の先頭**：動画の先頭を0秒とします
   - **時刻を指定する**：秒数を直接入力します
4. 「**解析を開始**」を押します。動画を1コマずつ送って骨格を読み取るため、**動画の長さと同じか、やや長い時間がかかります**

結果はリアルタイム計測と同じ形で表示され、波形もCSVも同じように出力できます。

読み取りが終わったあとは「**しきい値を変えて計算し直す**」が使えます。判定しきい値や0秒の位置を変えて押すと、動画を読み直さずに数え直します。うまく数えられていないときは、まず**撮影方向**（側方／前方）が動画と合っているかを確認してください。

**注意**

- 撮影方向は動画に合わせて選んでください。側方で撮った動画を前方モードで解析すると正しく数えられません
- 解析できるのは、そのブラウザが再生できる形式の動画だけです。iPhone で撮った MOV や、このアプリが保存した MP4・WebM はそのまま読み込めます
- 前方モードの比率は、動画全体を見てから基準の範囲を決め直すため、リアルタイム計測より安定します

## 使い方（リアルタイム計測）

1. 「基本情報」タブで**動作モード**に「リアルタイム計測」を選びます
2. **種目**を選びます（CS-30 または CS-10）
3. 「側方から撮影」か「前方から撮影」を選びます（**側方のほうが精度が高い**です）
4. **対象者の年代と性別**を選びます（基準値の判定に使います）
5. 「**計測に進む**」を押します。カメラの許可を求められたら許可します
6. 椅子と全身が画面に収まる位置にスマホやPCを固定します
7. 「**計測開始**」を押します
8. 「今から始めます。はいどうぞ」のアナウンス後に計測が始まります
9. 終了すると結果が表示され、基準値と比べた評価を音声で読み上げます

**CS-30 の場合**：30秒のカウントダウンが始まります。残り10秒で「残り10秒」とアナウンスし、残り3秒からは1秒ごとに音が鳴ります。30秒経過すると自動的に終了します。

**CS-10 の場合**：10回目に立ち上がった時点で自動的に終了します。

### 計測中の音声について

計測中は**回数を読み上げません**。1回ごとに短いビープ音が鳴り、画面中央に数字が大きく出るだけです。立ち方が不十分なときの声掛け（「しっかりまっすぐにたって」）も行いません。

検者が数を読み上げると対象者のペースや動作そのものが変わり、声掛けの有無で結果が変わってしまうためです。測定条件をそろえる必要があるので、計測中は介入しない仕様にしています。

音声でアナウンスするのは次の4つだけです。

- 開始の「今から始めます。はいどうぞ」
- CS-30 の「残り10秒」と、残り3秒からの1秒ごとの音
- 終了の「終了です」
- 終了後の結果のフィードバック

### 撮影のコツ

- 三脚やスタンドで固定してください。手持ちでは座標がぶれて精度が落ちます
- 全身、特に**足首まで**が画面に入るようにしてください
- 明るい場所で、背景と服装のコントラストがある方が検出が安定します
- 側方撮影では、体が真横を向くように配置してください

## 計測される項目

| 項目 | 内容 |
|---|---|
| 回数 | **立ち上がった時点**で1回としてカウント（CS-30の標準的な数え方） |
| 合計タイム | CS-10では10回目に立ち上がるまでの秒数 |
| 起立時間 | 座位しきい値を離れてから立位しきい値に到達するまで |
| 着座時間 | 立位しきい値を離れてから座位しきい値に到達するまで |
| 平均速度 | 判定信号の変化量 ÷ 所要時間 |
| ピーク速度 | 区間内の最大変化率（しきい値設定の影響を受けない） |
| 平均±標準偏差 | 10回分の集計（不偏標準偏差） |

## 基準値との比較とフィードバック

計測が終わると、選択した年代・性別に応じた基準値と比較し、**一言の評価を画面に表示し、同じ内容を音声で読み上げます。**

### CS-30 の判定

中谷敏昭ほか「30秒椅子立ち上がりテスト（CS-30テスト）成績の加齢変化と標準値の作成」（臨床スポーツ医学 20(3):349-355, 2003）の5段階評価基準を使用しています。

| 評価 | 読み上げる内容 |
|---|---|
| 優れている | 同年代の中でかなり優れた結果です |
| やや優れている | 同年代の平均を上回る良い結果です |
| ふつう | 同年代の平均的な範囲です |
| やや劣っている | 同年代の平均をやや下回っています |
| 劣っている | 同年代の平均を下回っています。下肢の筋力低下に注意しましょう |

65歳以上でサルコペニアのスクリーニング目安（男性17回・女性15回）を下回った場合は、その旨も画面に表示されます。

### CS-10 の判定

CS-10そのものには広く合意された年代別基準値がないため、**最初の5回に要した時間**を取り出し、5回椅子立ち上がりテストの基準と比較しています。最初の5回分の測定内容は5回立ち上がりテストと同一のため、この比較は妥当です。

| 年代 | 目安（これ以上で下肢機能低下の疑い） |
|---|---|
| 60〜69歳 | 11.4秒 |
| 70〜79歳 | 12.6秒 |
| 80歳以上 | 14.8秒 |
| 60歳未満 | 12秒（一般的な注意水準） |

10回全体の合計時間も併せて表示されますが、**これは基準値による判定には使っていません。**

### 判定を読むときの注意

- **これは診断ではありません。** スクリーニングの目安として使ってください
- CS-30の基準は2003年に作成されたものです。近年の高齢者は当時より身体機能が高い水準にあり、この基準では高い評価に偏るという報告があります（日本理学療法学術誌, 2026）
- 年代・性別を選び直すと、判定はその場で計算し直されます

### 所要時間の定義について

起立・着座の時間は「**しきい値を跨いだ区間**」の時間であり、動作全体の時間ではありません。
たとえば膝関節角度が95°→175°と変化する起立でも、しきい値が110°〜160°なら、その間の時間だけが計測されます。**しきい値を変えると数値も変わります。**

このため、被験者間や経時的な比較を行う場合は、

- **しきい値を固定して運用する**、または
- **しきい値の影響を受けないピーク速度で比較する**

のいずれかをおすすめします。ピーク速度は集計CSVに含まれています。

## 動画の保存

「動画の保存」パネルで、計測中の映像を動画ファイルとして残せます。既定はオフです。

| 設定 | 内容 |
|---|---|
| 計測中の動画を保存する | オンにすると、計測の開始から終了までが自動で録画されます |
| 録画する内容 | 「骨格線つき」＝判定に使った骨格を重ねた映像／「カメラ映像のみ」＝元の映像 |
| 対象者ID・メモ | フォルダ名とファイル名に反映されます（任意） |
| 保存のしかた | ZIPにまとめる／フォルダに保存／個別に保存 |
| PowerPointで使える形式に変換する | 保存時に通常のMP4へ作り直します（既定はオン） |
| マイクの音声も録音する | オンにすると開始・終了の読み上げや口頭指示が録画に入ります（既定はオフ） |
| 計測終了時にCSVも保存する | 動画と同じ名前でCSVを自動保存します（既定はオン） |
| 保存するCSV | 「集計＋時系列」または「集計のみ」 |

録画中は映像の左上に赤い「● REC」が点滅します。

**録画は、終了のチャイムと結果の読み上げが鳴り終わってから停止します。** 動画の末尾に「終了です。結果は◯回、同年代の平均的な範囲です」までが入るため、動画だけを見返しても結果が分かります。読み上げが終わってから約1秒の余韻を置いて停止するので、途中で切れることはありません。

そのため、計測終了から動画が保存されるまで数秒かかります。その間も「● REC」は点灯したままです。読み上げが長引いた場合でも、最長30秒で必ず停止して保存されます。

### 録画される音について

**カウント音とチャイムは録画に入ります。** アプリ内で合成している音のため、映像に直接ミックスされます。

**読み上げの声（開始の合図や終了後のフィードバック）は、そのままでは録画に入りません。** ブラウザの音声合成は、鳴った音を取り出す手段が仕様上用意されていないためです。これはアプリ側で解決できない制約です。

読み上げの声も残したい場合は、「**マイクの音声も録音する**」をオンにしてください。端末のスピーカーから出た読み上げをマイクが拾うため、結果として録画に入ります。検者の口頭指示や対象者の声も一緒に記録されるので、実際の記録としてはこちらの方が実用的です。

マイクを使うときの注意：

- 最初にオンにしたときブラウザがマイクの許可を求めます
- 端末の音量を上げておかないと読み上げが小さく入ります
- イヤホンを使うとスピーカーから音が出ないため、読み上げは録音されません
- **周囲の会話もすべて録音されます。** 対象者の個人情報が入り込む可能性があるため、取り扱いに注意してください

### PowerPointなどに貼り付けられる形式で保存します

ブラウザの録画機能（MediaRecorder）が出すMP4は、**fragmented MP4（細切れ形式）**と呼ばれる作りになっています。拡張子はmp4でも中身の構造が通常のMP4と違うため、PowerPointに挿入しようとすると「指定されたファイルからビデオを挿入できません」というエラーになります。

そこで、保存するときに**通常のMP4へ自動で作り直します**（「動画の保存」→「PowerPointで使える形式に変換する」。既定でオン）。

直すのは次の2点です。

| 問題 | 対処 |
|---|---|
| 細切れ形式（fragmented MP4） | サンプル表を作り直し、先頭にまとめた通常のMP4にする |
| フレーム間隔が一定でない | 全体の長さは保ったまま、1フレームあたりを均等にして一定フレームレートにする |

**再エンコードはしません。** 映像データはそのまま使い、入れ物の作りだけを組み替えるので、画質は変わらず、変換も一瞬で終わります（6秒の動画で数ミリ秒）。

### すでに保存した動画を直す

これまでに保存した動画がPowerPointに貼れない場合、作り直さなくても直せます。

1. 「動画の保存」パネルを開く
2. 下のほうにあるファイル選択から、直したいmp4を選ぶ
3. `（元の名前）_PowerPoint用.mp4` がダウンロードされる

すでに通常形式だった場合は「変換の必要はありません」と表示されます。

### それでも貼れないときは

ごくまれに、端末が**H.264以外の方式**（VP9など）で録画することがあります。その場合は形式を直しても、PowerPoint側が映像を読めません。変換後に「映像がvp09形式です」のような注意が出たときがこれにあたります。

この場合は、動画を別のソフトでH.264に変換し直す必要があります。無料の方法としては、VLCメディアプレーヤーの「変換／保存」や、HandBrakeなどが使えます。

なお、色の形式（yuvj420p など）は録画した端末の符号化器が決めるもので、入れ物を直すだけでは変えられません。これが原因で読めない場合も、同じく再エンコードが必要です。

### 保存形式について

**MP4で保存されます。** Chrome・Edge・Safari の最新版はMP4での録画に対応しています。

対応していない古いブラウザではWebM形式になり、その旨が画面に表示されます。WebMはVLCなど多くのプレーヤーで再生できますが、MP4が必要な場合はブラウザを更新してください。

### 保存先について

動画は**ブラウザのダウンロードフォルダ**に保存されます。

**重要：ブラウザの仕組み上、「アプリと同じ場所」への保存はできません。** このアプリはWebサーバー上に置かれているため、ブラウザからその場所へ書き込むことは許可されていません。

#### 毎回の確認ダイアログを消す設定

初期状態のブラウザだと、保存のたびに保存先を尋ねられることがあります。次の設定をしておくと、**確認なしで毎回同じフォルダへ自動保存**されます。

**Windows / Mac（Chrome・Edge）**

1. ブラウザの「⋮」メニュー →「設定」を開きます
2. 左側の「ダウンロード」を選びます
3. 「**ダウンロード前に各ファイルの保存場所を確認する**」を**オフ**にします
4. 同じ画面の「保存先」で、動画を貯めたいフォルダを指定できます

この設定にしておけば、計測が終わるたびに指定フォルダへ動画が自動で溜まっていきます。

**Android（Chrome）**

既定でダウンロードフォルダに自動保存されます。設定 →「ダウンロード」→「ファイルの保存場所を確認する」がオフになっていることを確認してください。

**iPhone（Safari）**

設定アプリ →「アプリ」→「Safari」→「ダウンロード」で保存先を指定できます。「ファイル」アプリの指定フォルダに保存されます。

### 計測ごとにまとめて保存する

ファイルが1か所に羅列されないよう、**1回の計測でできたファイルをひとまとめ**にして保存します。「保存のしかた」で方式を選べます。

#### 対象者ID・メモ

計測前に「対象者ID・メモ」欄に記入すると、フォルダ名とファイル名に反映されます。誰の・何回目の計測かが一目で分かるようになります。集計CSVにも記録されます。

```
CS30_20260825_1830_A001_18reps
└─ 種目 ─ 日付 ─ 時刻 ─ ID ─ 結果
```

空欄のままでも計測できます。ファイル名に使えない文字（\ / : * ? " < > |）は自動的に置き換えられます。

#### 方式1：ZIPにまとめる（既定・全環境で使えます）

1回の計測が**1つのZIPファイル**としてダウンロードされます。展開するとフォルダになり、中に動画とCSVが入っています。

```
CS30_20260825_1830_A001_18reps.zip
└── CS30_20260825_1830_A001_18reps/
    ├── CS30_20260825_1830_A001_18reps.mp4
    ├── CS30_20260825_1830_A001_18reps_summary.csv
    └── CS30_20260825_1830_A001_18reps_timeseries.csv
```

ダウンロードフォルダには計測ごとに1ファイルだけが増えるため、羅列になりません。**Android・iPhoneでもこの方式が使えます。**

#### 方式2：フォルダに保存（Windows / Mac の Chrome・Edge のみ）

保存先フォルダを一度指定すると、その中に**計測ごとのサブフォルダが自動で作られ**、ファイルが直接書き込まれます。ZIPを展開する手間がありません。

1. 「保存のしかた」で「フォルダに保存」を選びます
2. 「保存先フォルダを選ぶ」を押し、フォルダを指定して書き込みを許可します
3. 以降の計測は、そのフォルダ内に `CS30_日付_時刻_ID_結果` という名前のフォルダが作られ、その中に保存されます

```
指定したフォルダ/
├── CS30_20260825_1830_A001_18reps/
│   ├── ....mp4
│   ├── ..._summary.csv
│   └── ..._timeseries.csv
└── CS30_20260825_1845_A002_15reps/
    └── ...
```

**スマートフォンではこの方式は使えません**（ブラウザが対応していないため）。選択すると画面に案内が出ます。アプリを開き直すとフォルダの再指定が必要です。

#### 方式3：個別に保存

従来どおり、ファイルを1つずつダウンロードフォルダへ保存します。

#### 補足

CSVの自動保存が不要なら「計測終了時にCSVも保存する」をオフにしてください。「集計のみ」を選べば、サイズの大きい時系列CSVを除けます。

動画は録画停止のあと数秒遅れて出来上がるため、**アプリはすべてのファイルがそろうのを待ってからまとめて保存します。** 録画をオフにしている場合はCSVのみで保存されます。

> 「個別に保存」を選んだ場合のみ、初回にブラウザが「複数のファイルをダウンロードしようとしています」と尋ねることがあります。「許可」を選べば以降は表示されません。ZIPは1ファイルなのでこの確認は出ません。

### 使うときの注意

- 録画は端末の処理を使うため、fpsが下がることがあります。動作が重い場合は「カメラ映像のみ」を選ぶか、録画をオフにしてください
- 動画は端末内にのみ保存され、外部には送信されません
- 計測を途中で「リセット」した場合、その録画は保存されずに破棄されます
- 締めの読み上げ中に「リセット」や「計測開始」を押した場合は、そこまでの録画が保存されます
- **対象者の映像を記録することになるため、事前に説明し同意を得てください。** 保管方法や保存期間についても、所属機関の規定に従ってください

## 骨格線の色

背景や服の色によって骨格線が見えにくくなることがあるため、**色を自動で選ぶ**ようにしています（カメラの設定 →「骨格線の色」→ 自動）。

骨格の周辺の画素を実際に読み取り、背景の平均色とばらつきから最も見分けやすい色を選びます。背景が単色に近い場合は白または黒、明暗が混在している場合は白黒だとどこかで必ず重なるため、マゼンタ・シアン・黄緑などの鮮やかな色が選ばれます。

**色は各回の開始時に決まり、その回のあいだは固定されます。** 動作の途中で色が変わるとちらついて見づらいためです。回ごとには変わる場合があります。どの回にどの色が使われたかは集計CSVに記録されます。

自動が合わない場合は、同じ設定からマゼンタ・シアン・黄緑・オレンジ・白・黒を手動で選べます。

> 「映像の表示方式」が「ビデオ直接表示」のときは画素を読み取れないため、自動選択は働きません。「キャンバス描画」でお使いください。

## 姿勢と重心

計測が終わると「姿勢と重心」パネルに、体の傾きと重心の動きが表示されます。

### 偏位の見かた

両足首を結んだ**中点を0**とし、そこから頭部・肩・骨盤がどれだけ横にずれているかを、**肩幅を100%とした比**で表します。体格による差が出ないようにするためです。

| 撮影方向 | 正の値 | 負の値 |
|---|---|---|
| 前方から | 対象者から見て**左**寄り | 対象者から見て**右**寄り |
| 側方から | **前**寄り | **後ろ**寄り |

符号は解剖学的な左右（どちらが左肩か）から決めているため、**カメラを反対側に置いても、左右反転表示にしても、判定は変わりません。** 側方の前後判定は、つま先とかかとの位置関係から向きを決めています。

表示される項目は、頭部の偏位、肩の偏位、骨盤の偏位、体幹の傾き（鉛直からの角度）で、それぞれ平均±標準偏差と最大値、そして「左寄り」「前傾」などの判定が付きます。前方撮影では肩の水平傾き（左右どちらの肩が下がっているか）も表示されます。

### 重心のリアルタイム表示

計測中、重心の位置と軌跡が**その場で**表示されます。

**映像への重ね描き**

カメラ映像の上に、現在の重心が紫の丸と十字で表示されます。どんな背景でも見えるよう白い縁取りを付けています。直近の軌跡が尾を引くように描かれ、古い部分ほど薄くなります。オレンジの破線は両足首の中点を通る鉛直線で、重心がそこからどれだけ前後（左右）にずれているかが一目で分かります。

**ライブグラフ**

映像の下に、重心の動きがリアルタイムで描かれます。上部の選択で3つの見かたを切り替えられます。

| 表示 | 内容 |
|---|---|
| 軌跡（左右×高さ） | 横軸が左右（側方撮影なら前後）、縦軸が高さの2次元軌跡。立ち座りの往復がループとして見えます |
| 高さの推移 | 横軸が時間。上下動の周期とリズムが分かります |
| 左右の推移 | 横軸が時間。ふらつきや左右への偏りが分かります |

**数値表示**

映像のすぐ下に、重心の左右位置（側方撮影なら前後）と高さが数値で出ます。両足首の中点を0、肩幅を1とした相対値です。

**設定**

カメラの設定パネルで次を変えられます。

- 重心を映像に重ねて表示（オン／オフ）
- 軌跡を残す長さ（1.5秒／3秒／5秒／計測の全体）

既定は3秒です。動作のリズムを見るならこのくらいが見やすく、1周期の形を詳しく見たいときは「計測の全体」にすると全部の軌跡が重なって残ります。

> 端末への負担を抑えるため、グラフの描き直しは毎秒15回程度に間引いています。映像への重ね描きは毎フレーム更新されます。

### 重心

全身の重心は、**Winterの身体分節パラメータ**（頭頸部・体幹・上腕・前腕/手・大腿・下腿・足部の質量比と、各分節内の重心位置）を用いて加重平均で推定しています。股関節の中点で代用するより実際の重心に近い値になります。

検証では、直立姿勢で頭頂から45.2%の位置に重心が来ました。成人の全身重心は身長の約55〜57%（頭頂から43〜45%）とされており、妥当な値です。腕が画面から外れるなど一部の分節が検出できない場合は、その分節を除いて残りで再計算します。

パネルには重心の水平方向の振れ幅と上下移動量が表示されます。計測中のリアルタイム表示とは別に、**計測後の10回分の重ねがきは「波形を見る」→「重心の軌跡」タブ**で確認できます。

時系列CSVには、重心の座標が2通りで記録されます。

- **重心X / 重心Y**：画面上の正規化座標（0〜1。左上が原点）
- **重心相対X / 重心相対Y**：両足首の中点を原点、肩幅を1とした相対座標

体格やカメラ距離の影響を除いて比較したいときは相対座標を、画像に重ねて描き直したいときは画面座標を使ってください。あわせて両足首中点の座標と換算に使った尺度（肩幅）も記録しているので、相互に変換できます。

- 横軸が左右（側方撮影なら前後）、縦軸が高さです
- 両足首の中点を原点、肩幅を1とした相対座標です
- ■が動作の開始点、●が起立完了（立位到達）の時点です
- 縦の破線が両足首の中点で、ここからどれだけ振れているかが読み取れます
- 10回分が重ねて描かれるので、回を追うごとに軌跡が乱れていないか（疲労の影響）を見られます

### 判定を読むときの注意

**カメラの設置がずれていると、偏りがあるように計測されます。** 正面（または真横）から、レンズの高さを対象者の腰の高さに合わせて、三脚などで固定して撮影してください。斜めから撮ると、実際には真っすぐでも一方向に偏った値が出ます。

これは画像上の見え方に基づく評価であり、身体機能の診断ではありません。

## 波形とCSV

### 波形を見る

「波形を見る」ボタンで全画面グラフが開きます。

- 上部のタブで信号を切り替えられます（重心の軌跡、膝関節角度、股関節角度、前方比率、肩・股関節・膝・足首のX/Y座標、検出信頼度、頭部/肩/骨盤の偏位、体幹の傾き、肩の水平傾き、重心の左右位置と高さ）
- 10回分が色分けされて重ねがきされます
- 丸印は各回の起立完了（立位到達）時点です
- 判定に使った信号には、立位・座位のしきい値が破線で表示されます
- 「時間軸を0〜100%に正規化」：所要時間の異なる回どうしを波形の形で比較できます
- 「全体の連続波形」：10回分を切らずに1本の時系列として表示します

### CSV出力

| ボタン | 内容 |
|---|---|
| CSV（時系列） | 1フレームごとの全データ。経過時間、回、局面、判定ゾーン、膝関節角度、股関節角度、前方比率、各ランドマークのXY座標、検出信頼度、頭部・肩・骨盤の偏位、体幹の傾き、肩の水平傾き、**重心座標（画面座標と相対座標の両方）、重心速度、両足首中点の座標、換算に使った尺度** |
| CSV（集計） | 1回ごとの各時刻・所要時間・速度、平均・標準偏差、基準値との判定、姿勢と重心のまとめ、**重心速度の平均／標準偏差／最大、重心の総移動距離と1回あたりの移動距離**、各回の骨格線の色 |

どちらも Excel で文字化けしないよう BOM 付きで出力されます。グラフに使っている項目がそのまま列になっているため、Excel や統計ソフトで自由に解析し直せます。

## しきい値の調整

初期値では厳しすぎたり緩すぎたりすることがあります。「判定しきい値を調整」から変更してください。

| 項目 | 初期値 | 説明 |
|---|---|---|
| 立位角度（側方） | 160° | 膝がこれ以上伸びたら立位と判定 |
| 座位角度（側方） | 110° | 膝がこれ以下に曲がったら座位と判定 |
| 立位比率（前方） | 80% | 縦方向の伸びがこれ以上で立位 |
| 座位比率（前方） | 30% | 縦方向の縮みがこれ以下で座位 |

**カウントされない場合**は立位角度を下げる（例：160→150）、**動いていないのにカウントされる場合**は座位角度を下げてください。

前方モードは計測開始直後の動きから最小値・最大値を学習する方式です。開始前に一度大きく立ち座りしておくと安定します。

## うまく動かないとき

アプリ下部の「**診断情報**」を開いてください。赤字の項目が原因です。

| 症状 | 確認すること |
|---|---|
| カメラが起動しない | 「httpsか」が「はい」になっているか。いいえなら公開URLから開き直す |
| 映像が真っ黒 | 「次のカメラに切り替え」を試す。「映像の表示方式」を切り替える |
| 変なカメラが選ばれる | ⚠マークの付いたデバイスはカメラではない可能性。別のものを選ぶ |
| 骨格が検出されない | 全身（足首まで）が映っているか、明るさが足りているか |
| 音声が出ない | 「音声をテスト再生」を押す。端末に日本語音声が入っているか |
| コンソールに sw.js の404が出る | index.html だけを単体で開いています。5つのファイルを一緒に配置してください。アプリの動作自体には影響しません |
| 動画が保存されない | ブラウザのダウンロードがブロックされていないか確認。「動画の保存」がオンになっているか確認 |
| フォルダに保存が選べない | スマートフォンでは使えません。「ZIPにまとめる」をお使いください |
| 保存が数秒遅れる | 動画の書き出しを待っています。すべてそろってから1つにまとめて保存します |
| スイッチが切り替わらない | 古い版の不具合です。最新のファイルに差し替えてください |
| 動画が真っ黒 | 「録画する内容」を「カメラ映像のみ」に変えて試す |
| PowerPointに貼れない | 「PowerPointで使える形式に変換する」がオンか確認。過去の動画は「動画の保存」パネルのファイル選択から直せます |
| 変換後も貼れない | 映像がH.264以外（VP9など）の可能性。VLCやHandBrakeでH.264に変換し直してください |
| カウントされない | しきい値を調整する。波形を見て、線がしきい値の破線を越えているか確認 |

## 注意事項

このアプリは研究・記録の補助を目的としたものです。医療機器ではなく、診断や治療の判断に用いるものではありません。表示される基準値との比較はあくまで目安であり、診断ではありません。臨床評価として使用する場合は、従来の徒手計測と併用し、事前に妥当性の確認を行ってください。

映像とデータは端末内でのみ処理され、外部に送信・保存されることはありません。CSVと動画も端末内にのみ保存されます。動画を保存する場合は、対象者への説明と同意の取得、および保管方法について所属機関の規定に従ってください。
